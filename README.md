# 💻 Exercício 01: Fundamentos de R (Parte A)

Bem-vindo(a) ao primeiro exercício de Análise de Dados em R com correção automática. 

## 📝 Instruções Passo a Passo

1. **Clone o repositório:** Faça o clone deste repositório para o seu computador utilizando o RStudio (ou a interface Git da sua preferência).
2. **Abra o arquivo da tarefa:** No RStudio, localize e abra o arquivo chamado `exercicio_01.qmd`. 
3. **Resolva os problemas:** Leia atentamente a narrativa no documento e escreva o seu código em R **apenas dentro dos blocos de código**.
4. **Salve o documento:** Após preencher suas respostas, salve o arquivo (`Ctrl + S` ou `Cmd + S`).
5. **Envie para correção (Push):** Faça o *Commit* das suas alterações com uma mensagem descritiva (ex: "Finaliza vetor de grupos") e, em seguida, faça o *Push* para enviar seu código de volta ao GitHub.

## 🤖 Como funciona a correção automática?

Assim que você fizer o *Push*, os servidores do GitHub vão rodar o seu código invisivelmente e verificar se as suas respostas estão corretas. Isso leva apenas alguns segundos!

* Se aparecer um **Check Verde (✅)** ao lado do seu commit: Parabéns! Seu código passou em todos os testes matemáticos e lógicos. Tarefa concluída!
* Se aparecer um **X Vermelho (❌)**: Algo não saiu como esperado. Não se preocupe! Clique no "X" vermelho ou vá até a aba **Actions** na parte superior do repositório para ler a mensagem de erro (ela dará uma dica do que deu errado). Corrija o código no seu RStudio, salve e **faça um novo Commit/Push**. Você pode tentar quantas vezes precisar!

## ⚠️ Avisos Críticos (Não faça isso!)

Para que o robô corretor (Autograding) funcione perfeitamente, por favor, respeite as duas regras de ouro abaixo:

* **NÃO renomeie o arquivo `exercicio_01_A.qmd`.** O robô está programado para procurar exatamente por este nome. Se você mudar para "meu_exercicio.qmd", ele lhe dará nota zero.
* **NÃO apague ou modifique o arquivo `test_exercicio_01_A.R`.** Este é o gabarito oculto que o professor desenhou para avaliar a sua prova. Se ele for alterado, o sistema reportará adulteração.
